# nminhios store — bản xem trước giao diện

Đây là bản frontend tĩnh để xem giao diện trên GitHub Pages. Dữ liệu sản phẩm và giá đều là minh họa.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Tải toàn bộ nội dung thư mục này lên repository (file `index.html` phải nằm ở thư mục gốc).
3. Mở **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**, branch `main`, folder `/(root)`, rồi bấm **Save**.
5. Chờ GitHub hoàn tất triển khai, mở URL Pages được hiển thị trong mục Pages.

## Giới hạn
- Không có backend hoặc cơ sở dữ liệu.
- Đăng nhập, tạo đơn, thanh toán, giao key và trang quản trị không hoạt động thật.
- Các sản phẩm, tồn kho và giá trong `static/preview-api.js` là dữ liệu minh họa, không phải hàng hóa có thật.
- Đây là bản chỉ để xem bố cục; không dùng để bán hàng.
